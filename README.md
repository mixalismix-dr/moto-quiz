# Moto Ready

Στατική web εφαρμογή για προπόνηση στις ερωτήσεις διπλώματος μοτοσυκλέτας.

## Τι κάνει

- Δίνει τεστ 10 ερωτήσεων.
- Υπολογίζει σκορ στο τέλος.
- Δείχνει πόσες απαντήσεις ήταν σωστές και πόσες λάθος.
- Στις λάθος απαντήσεις εμφανίζει τη σωστή λύση.
- Κρατάει συνολικό ποσοστό ετοιμότητας `0-100%`.
- Επαναφέρει συχνότερα τις ερωτήσεις που δυσκολεύουν τον υποψήφιο.

## Ανέβασμα σε GitHub Pages

1. Κάνε push όλα τα αρχεία σε ένα GitHub repository.
2. Στο GitHub άνοιξε `Settings > Pages`.
3. Στο `Build and deployment` διάλεξε:
   `Source: Deploy from a branch`
4. Επίλεξε το branch σου, συνήθως `main`, και φάκελο `/root`.
5. Πάτησε `Save`.
6. Μετά από λίγο το site θα είναι online στο URL που θα σου δείξει το GitHub Pages.

## Αρχεία

- `index.html`: δομή της εφαρμογής
- `styles.css`: εμφάνιση
- `app.js`: λογική quiz, adaptive repetition, αποθήκευση προόδου
- `questions.js`: dataset ερωτήσεων
